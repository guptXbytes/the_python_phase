# Password Manager

## Description
The passwords for different profiles/applications can stored and the passwords are encrypted.

## Features
1.Asks for the User to write user_name and password or view the user_name and password till the user enters to quit.
2.The passwords for different profiles is stored in new Text file.
3.A .key file is created and key is being is stored in it and the key is used for encryption/decryption of the password.
4.The passwords are being encrypted in the Text file using the key.
5.The User can view all the profiles.
