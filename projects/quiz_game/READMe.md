#quiz_game_project

#Descripition
In this project the user is asked to play this quiz and based on his response of yes or no, if the user types yes there are some inbuilt questions which are implemented using the if-else and at the end the score and percentage is being printed presenting the result of the game.

#features
1.Askst for the questions.
2.For every correct answer , score is awarded.
3.For the score obtained by a user, percentage is being obtained.
