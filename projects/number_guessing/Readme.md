# number_guessing 

#what does it do?
It generates a random number and lets the user guess it till the correct guess is found.

#what are its features?
1.It asks the user for the maximum number.
2.If the number is not entered, the user is exited.
3.It generates the random number.
4.It lets the user guess till the correct guess is found.
5.Every guess attempt is counted
6.It generates in how many attempts the guess was correct.

#what technologies did i use?
1.imported the random module.
2.if-else statements
3.while loop
4.print for printing the attempt count.

#how do i run it?
python number_guessing.py
