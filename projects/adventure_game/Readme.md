# choose_your_own_adventure_game

## Description 
This program lets the user create its adventure and travel through the directions being feeded.

## Features
1.The user enters his name.
2.The game welcomes the user.
3.The input is taken to start the adventure descriped in the prompt.
4.The input is taken repeatedly for every direction / action it chooses.
5.If the input is invalid, the user loses the game.
6.The user has to choose correct path and discover the path to winning the game.
7.The game thanks the user for playing...

## Tech Stack 
 Python

## How to run 
python adventure_game.py
