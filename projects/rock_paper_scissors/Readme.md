# rock_paper_scissors game

#Description.
This project lets the user play the rock, paper , scissors game with the computer.

#Features.
1.The user has the option to play the game till he needs to quit.
2.The computer takes the option by using the random module.
3.If the input entered is out of options , it is redirected to again ask the input.
4.The comp_option and user_option are being displayed.
5.The program goes with the game rules and give the winner/ loser/ draw everytime the input is entered.
6.When the user exits the game, the total wins by both comp and user is displayed.
7.The final winner is displayed.
